# 同一账号跨设备同步

- 用户在新版 App 使用原手机号格式账号和密码首次登录时，系统应验证旧身份并创建 Supabase 会话；以后应直接使用 Supabase 登录和刷新。
- 用户切换账号时，系统应隔离每个账号的本机数据库，不得上传前一账号的资料。
- 用户在离线时修改任务、成长、经期或用药记录，系统应保留修改并在恢复连接后上传。
- 用户在第二台设备登录同一账号时，系统应下载该账号的全部已同步业务记录。
- 两台设备修改同一记录时，系统应保留未上传的本机修改并请求用户选择冲突版本。
- 用户从旧版升级且本机旧会话账号与新会话账号相同时，系统应无损复制旧数据库并保留源文件；不匹配时不得自动导入。
- 新增的业务表应全部使用 `todo_` 前缀，启用按 Supabase 用户 ID 隔离的 RLS，保留项目原有表。
- 手机端不得包含服务端密钥；本机健康字段继续加密保存。
